Secure Roku pairing

  • Cryptographically random, single-use pairing code expires after 15 minutes.
  • The code can be claimed only from a Ring-authorized browser session.
  • A separate 256-bit polling secret prevents the code alone from retrieving a credential.
  • A separate 256-bit bearer device token authenticates later Roku API requests over HTTPS.
  • Pairing claims and polling are rate-limited.

Two disconnect scopes

Roku channel: Disconnect Ring Account removes that Roku’s server-side credential and clears its local token and cached account state. Other Roku devices and the Ring integration remain connected.

Ring Appstore: Disconnecting Camera Dashboard stops processing for the Ring account and triggers deletion of its authorization tokens, events, media, sessions, and all pairing records.
